Ai0 Video Creator

全功能 Tauri v2 桌面AI视频创作套件，同时支持本地ComfyUI离线工作流与云端API双后端。 一站式制作短剧、多语言翻译配音视频、单词教学短片、对话片段、原创叙事故事。

GitHub 项目仓库 完整中文文档

两种运行模式

本地离线模式（对接ComfyUI）

连接本地ComfyUI，原生支持LTX-2.3视频模型，全部渲染运算在本地显卡完成，无任何素材上传云端。针对RTX3060 12G低显存显卡做内存优化。

云端API模式

无高性能独立显卡设备专用，切换远程云端视频生成接口，在本软件内完成全类型视频内容制作。

支持制作的全部视频类型

  • 人物形象统一的古风/奇幻短剧系列
  • 自动配音、内嵌字幕的多语言AI翻译影片
  • 带场景对话的英语单词教学短片
  • 独立剧情对话片段，用于剧本创作练习
  • 9:16竖屏电影质感原创故事短片（1080P 24帧）

核心功能模块

视觉资产人物库

存储可复用IP角色、场景环境、道具素材，锁定人物五官特征，解决多镜头画面人物闪烁问题。

剧本综合编辑器

撰写场景对白、旁白与电影级渲染提示词，本地大模型完成双语翻译、人物口吻定制，一键绑定素材提交ComfyUI渲染。

Qwen3本地语音合成

自定义音色克隆，批量生成剧本配音，区分旁白、青年、老人等独立声线，适配多角色影视剧本。

多轨道时间线编辑器

自动导入ComfyUI渲染片段，分离视频/音频/字幕轨道，实时预览成片，FFmpeg一键导出MP4成品。

批量视频翻译工作站

离线完整流水线：音频分离、语音转写、跨语言翻译、配音、LTX唇形同步修正，用于现有AI影片重制字幕与配音。

内置Ollama本地对话助手

内置本地大模型沙箱，可写剧本、翻译文本、调试渲染提示词、自定义系统行为指令，无需额外工具。

ComfyUI 必需启动命令

启动ComfyUI时开启跨域头与低显存优化，允许桌面软件连接本地服务：

python main.py --listen 0.0.0.0 --enable-cors-header --lowvram
  • --enable-cors-header：允许Tauri桌面程序跨域请求
  • --lowvram：修复RTX3060 12G等显卡显存溢出报错

硬件配置要求

  • 最低配置：RTX3060 12G（低显存模式，FP8软件模拟运算）
  • 推荐配置：RTX4060Ti 16G及以上（硬件FP8加速LTX视频渲染）
  • 无独立显卡：切换云端API模式，仅使用CPU运行
